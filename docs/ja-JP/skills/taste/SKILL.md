# Taste（動画クリエイティブディレクション / テイスト）

ほとんどのAI動画制作のアドバイスは「*いかにフレームをレンダリングするか*」で止まっています。本スキルはその一段上にあるレイヤーを扱います: **生成物の無秩序な山ではなく、1つの意図を持った作品として伝わるようにするために、フレームがどう見えるべきか、どの順序で並べるべきか、どのようなリズムでカットすべきか。**

本スキルは、保存されたリール動画群と約70種類に及ぶ視覚ジャンルライブラリから蒸留された、**angelcore / cloud-trance / hyperpop** ファミリー（Bladeeの「Silver Surfer」期の浮遊感あるトランスと重厚なエンジェルコアの融合）という特定のテイストを体系化しています。あえて意見を強く持たせています（opinionated）。テイストとはメニューの一覧ではなく、確固たる視点そのものだからです。

> 付随する `references/genre-taxonomy.md` に全ジャンルのカタログが記載されています。
> 本ファイルはアクション可能なレイヤー（ムード、文法、パイプライン、ビート同期ショット計画）を提供します。

## 有効化のタイミング

- **ミュージックビデオ（MV）**、リリックビデオ、ファンカム、またはビジュアライザーを制作するとき。
- 情報の伝達よりも「*フィーリング（質感・空気感）*」が重要となるショート動画（**リール/エディット**）を制作するとき。
- 単発の思いつきではなく、一貫した方向性を持ったプロンプトで **AI Bロール生成**（fal.ai, Veo, Kling 等）を行いたいとき。
- レンダリング前に**ムードボード**を組み立てたり、視覚ジャンルを選定するとき。
- ユーザーが「テイスト（taste）」「Xのような雰囲気にして」「方向性を決めて」「angelcore」「cloud trance」「hyperpop edit」「Bladee」「dreamcore」と言ったとき、または特定のリファレンスを挙げたとき。
- 現在の動画は動いているものの、平板で退屈、AI生成感丸出し、あるいはスタイルとしてチグハグなとき。

本スキルは、`video-editing`（メカニクス・編集技法）および `remotion-video-creation`（レンダラー）の**上位**に位置します。これらは「どのように作るか」を担当し、本スキルは「**何を、なぜ作るのか**」を担当します。

## コアテーゼ（基本思想）

1. **テイストは最後のレイヤーであり、かつ最初に決定されなければならない。** `video-editing` は「テイストは人間の最後の仕上げである」と正しく述べています。しかし罠があります: 最後にしかテイストを決めない場合、上流でのすべての生成やカット割りは単なる当てずっぽうになってしまいます。最初のプロンプトを打つ*前*に方向性を定め、それをすべての制約として機能させてください。
2. **一貫性は目新しさに勝る。** 30種類の異なるルックを並べるよりも、1つのルックで貫かれた30ショットの方がはるかに優れています。ジャンル名の指定は、一貫性を自動的に担保する制約となります。
3. **映像ではなく、楽曲に合わせてカットする。** MVにおいて、タイムラインとは波形そのものです。すべてのハードカットはビート（拍）またはトランジェント（アタック音）に着地しなければなりません。
4. **選別して生成し、冷徹に編集する。** AIは実在しないBロールを作り出せますが、テイストを生み出すことはできません。生成した素材の80%は容赦なく捨ててください。

## 美的ボキャブラリ（蒸留されたジャンル体系）

ジャンル名は**プロンプトとグレーディングの完全なプリセット**です。ジャンルを1つ選ぶだけで、パレット、質感、ライティング、被写体が1つのまとまりとして自動的に決定されます。

ジャンルはいくつかのファミリーに分類されます。**メイン**のファミリーを1つ選び、アクセントとして最大**もう1つ**を選びます:

| ファミリー | 含まれるジャンル | 印象・質感 |
|--------|-------------|----------|
| **Ethereal / divine（天上的/神聖）** | spiritualism, glacial folk, beacons, zen core, fairy tale | 無重力、神聖、発光、柔らかさ |
| **Hyperpop / Y2K-cyber** | cyberdelia, acid house, acid nora, neo aggressano, new liquid | 光沢、クロム、ネオン、カワイイサイバー |
| **Dark / occult（暗黒/神秘）** | dark academia, smoke nostalgia, communist core, abstract tech | ハイコントラスト、不穏、フィルムグレイン |
| **Retro / print（レトロ/印刷）** | retro surfers, art deco, adventure pulp, classic advertising, magazine collage, bumper stickers | フラット、グラフィック、ハーフトーン、ノスタルジック |
| **Organic / textural（有機的/質感）** | microbiology core, weaving patterns, fruitage retro, cozy blanket, pacific punk wave | 触覚的、マクロ撮影、織物、濡れ感 |
| **Systemic / data（構造的/データ）** | numbers, mazes, code web, heatmap, pixel, 8-bit | グリッド、ジェネレーティブ、図略的 |

**本プロジェクトにおいて**、メインは **Ethereal / divine**、アクセントは **Hyperpop / Y2K-cyber** です — すなわち、神聖な光とクリスタルのブルームに、クロムとネオンのアクセントが差し込む世界観です。この組み合わせこそが、angelcore × cloud-trance の本質です。

## ムードシステム — angelcore × cloud-trance

最も優れたリファレンスから直接蒸留された具体的なグレーディング基準です。

### カラーパレット
- **ベース:** 漆黒の虚無（#05060a）とボーンホワイト（骨白色 #f4f1ea）。ほとんどのフレームはこのどちらかです。
- **神聖アクセント:** 溶融ゴールド / 熾火オレンジ（#ffb24d → #ff7a18） — 暗闇の中の*唯一の温かい光源*。
- **クリスタルアクセント:** 玉虫色のバイオレット→シアン→マゼンタのボケ（#8a6bff, #4fc3ff, #ff6ad5） — 明るいフレームで使われるハイパーポップなブルーム。
- **危機アクセント（極めて限定的に使用）:** モノクロの中に差し込む単一の赤色発光（#ff2a2a） — 1〜2回だけのショックカット用。
- **ハイパーポップ被写体:** キャンディピンクの髪 / クロム / 青空を背景にした光沢のある白。

ルール: **1ショットにつきアクセントカラーは1色のみ。** ゴールドは暗いフレーム、玉虫色は明るいフレームに配置し、決して1ショット内で混在させてはなりません。

### ライティングと質感
- 単一の温かい光源（熾火のブルーム、神聖な光線）によって貫かれる暗闇。深い黒とハイコントラスト。
- クリスタル/グリッターのボケ、レンズフレア、ブルーム、光漏れ（ライトリーク） — 汚れた質感ではなく*天上的（heavenly）*な輝き。
- 暗いフレームにはフィルムグレインと微細な色収差を適用。明るいフレームにはクリーンな光沢感を維持。
- 負の空間（暗黒）に浮かび上がるマクロ撮影のディテール: 黒背景の中央に配置された象徴的な被写体（鍵、瞳、歯車、花びら、水滴）。
- 被写体: 翼を持つ人物、雲、後光、天使、結晶構造、キャンディサイバーなポートレート。

### モーション（動き）
- 浮遊感のあるゆっくりとしたカメラワーク（ドリフト、スロープッシュ、スローオービット） — *cloud（雲）* トランスの浮遊感。
- 急激なスピード変化は楽曲のドロップ時のみ。それ以外はすべて深呼吸するようにゆったりと動く。
- 上昇する微粒子（火の粉、塵、グリッター） — 上方向への動き ＝ 昇天（ascension）。

## 編集文法（The Editing Grammar）

リファレンスから抽出された、このスタイルを定義づける必須テクニック:

1. **ビート固定のハードカット（Beat-locked hard cuts）。** ヴァースやドロップでディゾルブ（フェード）を使ってはならない。キックに合わせてハードカットする。目にBPMを感じさせること。
2. **黒背景マクロインサート（Hero-on-black macro inserts）。** 黒い負の空間の中央に単一のシャープな被写体を配置し、1〜2ビート保持してカット。これらをリズミカルにモンタージュすることが cloud-trance のトレードマーク。
3. **ブルーム / 爆発による展開（Bloom / explosion reveal）。** アタック音に合わせて白い光または熾火のブルームがフレーム全体を白飛びさせ、次のショットへと解決する。「神聖な閃光（divine flash）」トランジション。
4. **モノクロ内のカラーポップ。** モノクロ映像の連続から、ダウンビートの瞬間に単一のカラー要素（赤い瞳、金色の炎、ピンクの髪など）を鮮烈に打ち込む。
5. **ドロップへのスピードランプ。** ドロップ直前の小節で映像をスローからファストへ加速させ、1拍目の頭（the one）でテンポに合わせてハードカット。

**禁止事項（Do-nots）:** テンポのあるセクションでのクロスフェードトランジション、1ショット内に複数のアクセントカラーを混在させること、音楽フレーズを超えて同じショットを長持ちさせること、画面上のUI表示（レターボックスやステータスバーは必ずクロップ除去）、同一タイムライン内でのアスペクト比の混在。

## パイプライン — ECC動画スキルの統合

本スキルは指揮者（Conductor）であり、各ECCスキルはその楽器です。

```
0. TASTE（本スキル）         レンダリング前にジャンル ＋ ムード ＋ 文法を決定
1. STRUCTURE (video-editing) 楽曲の構成: Intro/Verse/Drop/Bridge/Outro のタイムスタンプ定義
2. GENERATE (fal-ai-media)   ジャンル別プリセットでBロールを生成（80%は破棄）
3. CUT (video-editing/FFmpeg)ビート同期カット ＋ 9:16リフレーム。選定クリップをグリッド上に配置
4. COMPOSE (remotion)        オーバーレイ、ブルーム、リリック、ビート同期シーケンスの合成
5. MOTION (motion-* skills)  イージング曲線、光漏れ/粒子の動き、トランジションのタイミング
6. AUDIO (fal-ai-media)      カットを際立たせる効果音/ライザー（楽曲自体はDAWで制作）
7. POLISH                    上記パレットへのグレーディング、テンポの最終調整、書き出し
8. DISTRIBUTE (content-engine)プラットフォーム最適化版 ＋ キャプション/カバー画像の作成
```

## ビート計算（楽曲とカットの完全同期）

楽曲が **138 BPM** の場合:
- `1ビートあたりの秒数 = 60 / 138 = 0.43478秒`
- `1ビートあたりのフレーム数 = fps × 0.43478` → **24fps: 10.43フレーム**, **30fps: 13.04フレーム**, **60fps: 26.09フレーム**
- `1小節（4ビート） = 1.7391秒` → 30fps で **52.17フレーム**
- `8小節フレーズ = 13.913秒`

Remotion ではすべてのシーケンスの開始位置をビートにスナップさせます:
```ts
const FPS = 30;
const BPM = 138;
const beat = (n: number) => Math.round(n * (60 / BPM) * FPS); // beat(n) → フレーム番号
// ビート 0, 4, 8... でカット: <Sequence from={beat(0)} durationInFrames={beat(4)}> ...
```

## キー原則のまとめ

1. **最初の生成を行う前にジャンルを決める。** メイン1つ ＋ アクセント1つを選択。
2. **1ショットにつきアクセントカラーは1色のみ。** 暗闇には金、光の中には玉虫色、赤は1回だけ。
3. **すべてのハードカットはビートに着地させる。** ビート計算を活用し、テンポセクションでのトランジションは禁止。
4. **黒背景マクロが決定的な必殺技。** これをマスターしてヴァースを構成する。
5. **10本生成し、残すのは2本。** 一貫性はプロンプトをこねくり回すことからではなく、容赦ない選別から生まれる。
6. **UIの痕跡を完全にクロップする。** ステータスバーやキャプションを最終フレームに残さない。
7. **テイストは最初に決め、最後まで守り抜く。** 方針を定め、すべてのカットにおいてその一貫性を死守する。
