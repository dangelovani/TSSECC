# マーケティングキャンペーン (Marketing Campaign)

単に「公開して終わり」ではなく、確実にコンバージョン（成果）を生み出すローンチキャンペーンを計画・実行します。

## 発動タイミング

- プロダクトまたは新機能のローンチ計画時
- 1つのプロダクトブリーフから一連のコンテンツ群を構築する場合
- コピーを書く前にポジショニングとキャンペーンの切り口（アングル）を定義する場合
- チャネルをまたぐ複数のコンテンツ形式をオーケストレーションする場合
- コンバージョン品質とブランドの一貫性の観点からコピーをレビューする場合

## 妥協してはならない原則 (Non-Negotiables)

1. **コピーを書く前にポジショニングを定義すること:** すべてのコピーは切り口（アングル）から派生します。
2. **オーディエンスの言葉や懸念を思い込みで決めつけず、事前に徹底調査すること。**
3. **各成果物は、キャンペーン全体の流れにおいて1つの明確な目的を果たすこと。**
4. **あらゆるチャネル・形式において、曖昧な形容詞よりも「具体性」を優先すること。**
5. **すべてのチャネル、すべての制作物において「同一のブランドボイス（語り口）」を貫くこと。**
6. **品質ゲートを通過しないコピーは一切公開しないこと。**

## キャンペーンワークフロー

### フェーズ1: 調査 (Research)

`market-research` を活用して以下を実施：
- ターゲットオーディエンスのプロファイリング（JTBD：片づけるべき用事、恐れ・懸念、使用言語、既存の代替手段）
- 3社以上の直接・隣接競合の分析（ポジショニング、市場の空白、訴求メッセージの弱点）
- キャンペーンアングルで突くべき1〜3件のオーディエンスインサイトの特定

成果物: 簡潔なリサーチブリーフ（オーディエンスプロファイル + 競合サマリー + 重要インサイト）。

### フェーズ2: ポジショニング (Positioning)

以下を作成：
- コアベネフィットステートメント（1文、機能の羅列や専門用語を排除）
- ポジショニングフォーミュラ:「[プロダクト名] は [対象オーディエンス] が [仕組み] によって [求める成果] を達成できるよう支援します」
- キャンペーンアングル: キャンペーン全体が根差す特定の緊張感、インサイト、またはモーメント
- トーンプロファイル: 執筆前に固定（永続的で再利用可能なトーン確立には `brand-voice` に委譲）

ポジショニングとアングルが承認されるまで、本文コピーを書き始めてはなりません。

### フェーズ3: コンテンツ制作 (Content Production)

以下の順序で制作します（各レイヤーが次の制作物の土台となります）：

1. **ランディングページ（LP）コピー**（全セクション：ファーストビュー、課題、解決策、特徴、仕組み、実績・証拠、CTA）
2. **メールシーケンス**（各メールに1つの明確な目的を設定。アークに従う：課題提起 → 教育 → 痛みの強調 → 解決策 → 実績 → 緊急性 → 最終CTA）
3. **SNS投稿**（`content-engine` を通じたプラットフォームネイティブ形式。LinkedInとXはコピーの使い回しではなく、フォーマットごとに最適化）
4. **ショート動画スクリプト**（タイムスタンプ付き。画面と耳で理解できるよう記述し、単なる読み上げ原稿にしない）
5. **広告コピーバリアント**（異なるアングルやターゲットセグメントを検証する3〜4通りのバリアント）
6. **コンテンツカレンダー**（チャネル、種類、配信タイミング、依存関係を日別に整理したスケジュール）

### フェーズ4: レビュー (Review)

すべての成果物に以下のゲートを適用：
- ファーストビュー/最上部コピーに対する5秒テスト（誰のためか、何ができるか、なぜ今行動すべきかが一瞬で伝わるか）
- CTA監査（1つの成果物に1つ、具体的で、強要ではなく納得して押したくなる文言か）
- 全チャネルを通じたトーンの一貫性確認
- 主張・実績の監査（すべての主張が具体的であり、客観的に裏付け可能か）
- チャネル間の整合性（広告の訴求がLPと一致しているか、メール件名と本文にギャップがないか）

## 出力規約 (Output Contract)

完全なキャンペーンパックとして以下を提供します：

1. **ポジショニングブリーフ** — アングル、コアベネフィットステートメント、トーンプロファイル
2. **LPコピー** — ファーストビュー、課題、解決策、特徴、仕組み、実績、CTA
3. **メールシーケンス** — 日別・目的別の件名、プレビュー文、本文、CTA
4. **LinkedIn投稿** — 独自の切り口を持つ3本以上のネイティブ投稿
5. **X (Twitter) 投稿** — 5本以上の単独ポスト + 1本の長文スレッド
6. **ショート動画スクリプト** — 演出指示ノート付きのタイムスタンプ分割スクリプト2本以上
7. **広告コピーバリアント** — バリアントごとの短見出し/長見出し/本文
8. **コンテンツカレンダー** — チャネル、種別、配信時期、依存関係をまとめた日別スケジュール
9. **コピーレビューサマリー** — 公開前に確認すべき指摘事項と確認事項

## 品質ゲート (Quality Gate)

各制作物を納品する前に以下を確認：

- すべての成果物が同一の筆者によるトーンであること
- 空虚な最上級表現や無意味な形容詞が残っていないこと
- すべてのCTAが具体的かつ納得感のあるものであること（「詳細はこちら」「ここをクリック」などは禁止）
- 複数プラットフォーム間で同一のコピーをそのままコピペしていないこと
- ファーストビューのコピーが5秒テストを通過していること
- メールの件名と本文が合致していること（釣り見出しの禁止）
- 広告の訴求内容がLPの記載と完全に一致していること
- 同業他社の別プロダクトにそのまま差し替えても通用してしまうような没個性なコピーがないこと

## 絶対禁止事項 (Hard Bans)

以下のような表現が見つかった場合は即座に削除・書き直しを行います：

- 「革新的な (game-changing)」「革命的な」「世界最高峰の」「最先端の」などの手垢のついた表現
- 「今日の激しい競争環境において〜」といった紋切り型の導入
- 実際の期限に裏付けられていない偽りの緊急性
- 具体性のない空虚な社会的証明（「数千社が信頼」など）
- 一般的で退屈なCTA（「もっと詳しく」「クリックしてください」）
- 競合他社のキャンペーンにそのまま流用できてしまうような汎用的なコピー

## 関連スキル

- `brand-voice` — 原典からのボイスプロファイルの抽出（コンテンツ制作前に実行）
- `content-engine` — プラットフォーム最適化コンテンツの制作
- `crosspost` — マルチプラットフォーム配信
- `market-research` — オーディエンスおよび競合インテリジェンス
- `seo` — LPコピーのオンページ最適化
