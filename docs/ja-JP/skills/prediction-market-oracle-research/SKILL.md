# 予測市場オラクル調査 (Prediction Market Oracle Research)

予測市場をデータソース、予測入力値、オラクル的なシグナル、または意思決定インテリジェンス層として検討する際に本スキルを使用します。

## ガードレール

- 市場価格を客観的な事実（客観的真実）として扱ってはなりません。
- 投資助言や取引推奨を提供してはなりません。
- 取引所の仕組み、流動性、インセンティブ構造、解決（Resolution）ルールを、市場が示唆するシグナルと明確に区別して評価します。
- 価格操作の可能性、流動性の薄さ、市場の陳腐化、結果判定の曖昧さを明記します。
- オンチェーン連携や注文執行と連動するシステムの場合、書き込み権限を付与する前に必ず `llm-trading-agent-security` を実行してください。

## 調査ワークフロー

1. シグナルがどのような意思決定に役立てられるかを定義します。
2. 関連する市場、イベント、タグ、取引所を特定します。
3. タイムスタンプとソースリンクを付与して、市場織り込み確率を記録します。
4. シグナルの品質を評価します：
   - 流動性（Liquidity）
   - スプレッド（Spread）
   - 市場の経過期間（Market age）
   - トレーダーやインセンティブの集中度（判明している場合）
   - 結果解決権限機関（Resolution authority）
   - 地域制限や口座制限の有無
5. 開示資料、ニュース、世論調査、研究論文、顧客データ、内部KPIなどの非市場ソースと比較検証します。
6. 設定された意思決定に対して、そのシグナルが「利用可能」「信頼性低」「不適格」のいずれであるかを推奨します。

## 統合パターン

- **リサーチアシスタント:** 人間のアナリスト向けに出典根拠に基づいたコンテキストを提供。
- **ダッシュボードシグナル:** 内部指標と並べて市場織り込み確率を可視化。
- **エージェントメモリ入力:** 後から想起可能なタイムスタンプ付きシグナルとして保存。
- **アラート入力:** 確率、スプレッド、流動性がしきい値を超えた際に通知。
- **シナリオプランニング:** 取引を自動化することなく、複数の事象結果をシナリオ比較。

## 出力規約（Output Contract）

以下の構成で出力します：

1. 意思決定の背景 (Decision context)
2. 対象市場のソース (Market sources)
3. シグナルの品質評価 (Signal quality)
4. 比較対象ソース (Comparison sources)
5. 統合に関する推奨 (Integration recommendation)
6. 留意事項・制約 (Caveats)

末尾に必ず以下の文言を付記します：

```text
予測市場のシグナルは情報提供を目的とした入力データであり、投資助言ではありません。
```
