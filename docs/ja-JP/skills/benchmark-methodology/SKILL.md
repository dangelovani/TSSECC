# Benchmark Methodology（ベンチマーク手法）

定義された競合セットを、**比較可能で客観的に立証可能なスコア**に変換するためにこのスキルを使用します。各競合は、明示的な1〜5段階の評価基準（ルーブリック）に基づいて同一の9つの次元で評価され、統一されたプロファイルカードにまとめられます。一貫性が最も重要です。同一のエビデンスであれば、どの競合に対しても同じスコアが与えられる状態でなければ比較の意味がありません。

## 有効化のタイミング

- `competitive-platform-analysis` によるスコープ定義および階層化された競合セットのスコアリング準備が整ったとき
- 直感によるランク付けではなく、エビデンスに裏付けられた競合間の比較可能スコアが必要なとき
- クライアントの戦略的緊張関係（目標とするホワイトスペースを定義する対となる2軸）が確立されているとき
- `competitive-report-structure` で統合するためのプロファイルカードを作成するとき

## クライアントのポジショニング要件（最初に確立すること）

スコアリングを行う前に、クライアントのポジショニング要件（ポジショニングブリーフ）を定義します。以下の要素を含みます：

- **戦略的緊張関係（Strategic tension）** — その交差がクライアントの目標ホワイトスペースを示す2つの軸（例：記憶定着度 × 発注しやすさ）。次元9は常にこのクライアント固有の緊張関係となります。両極は個別に報告し、決して平均化してはなりません。
- **差別化要因（Differentiator）** — クライアントの参入障壁（堀）となる要素。ポジショニングの論理においてどの次元が最も重要かを規定します。
- **ブランドバランス（Brand balance）** — 意図された戦略的力点の比率構成。戦略的提言はこのバランスを崩してはならず、変動する場合は明示的な警告を要します。

## なぜこれらの評価次元なのか

クライアントはサービスの幅広さではなく、**2つの極の間に保たれた特定の緊張関係**に基づいて競合します。評価次元の重み付けはその参入障壁を反映しています。緊張関係を成す2つの極は**個別にスコアリングされ、決して平均化されません**。なぜなら、クライアントの戦略的な問いはまさに「競合がその両方を同時に達成できているかどうか」だからです。

## 9つの評価次元（重み付け付き）

重み付けは総合スコアの算出のためではなく、分析・要約時の重点を示すためのものです（誤った複合総合値は避けてください — バイアス管理を参照）。合計 ＝ 100%。

1. **ポジショニングの明確性と独自性（Positioning clarity & distinctiveness）** (18%) — 立ち位置が鋭く、独自性があり、即座に理解できるか？それとも凡庸か？
2. **ブランドボイス / 言語的独自性（Brand voice / verbal distinctiveness）** (15%) — コピーに固有のトーンがあるか？それともどこにでもある代理店構文か？
3. **ビジュアルアイデンティティとサイトのクラフト（Visual identity & site craft）** (15%) — ビジュアルシステムの品質と独自性。クラフトの証拠としてのWebサイト。
4. **サービスオファーとパッケージ化（Service offer & packaging）** (12%) — プロダクト化され明瞭か（名称付きのスプリントや監査など）？それとも曖昧か？パッケージ化の成熟度。
5. **エビデンスと信頼性（Evidence & credibility）** (12%) — クライアントの実名、定量化された成果、ケーススタディの深さ。単なる主張を超えた証拠。
6. **エンタープライズ適合性 / 商業的成熟度（Enterprise-readiness / commercial maturity）** (10%) — SaaS、フィンテック、B2B、大企業の案件を獲得・維持できるシグナル（プロセス、ロゴ実績、規模、契約対応力）。
7. **ソートリーダーシップ / 発信の存在感（Thought leadership / content presence）** (8%) — 独自の見解: 執筆、登壇、ニュースレター、フレームワーク。量よりも深さ。
8. **価格の透明性とエンゲージメントモデル（Pricing transparency & engagement model）** (5%) — 価格設定や契約モデルが明瞭か？パッケージ化 vs 個別見積もり vs 不透明。
9. **[クライアントの戦略的緊張関係]** (フラグとして5%; **両極をそれぞれスコアリングし、個別に報告すること**) — クライアントのポジショニング要件から緊張関係の名称と軸の説明を読み取ります。両極をプロットします（そのギャップこそが洞察です）。クライアントのターゲット象限にすでに誰が存在しているかが、最も重要な発見となります。

## スコアリングルーブリック（1〜5点、次元1〜8に適用）

すべてのスコアを観察可能なエビデンスに固定します。以下は汎用的な記述子です。次元ごとに具体化しつつ、水準の意味は一定に保ちます。

- **1 — 欠如 / 凡庸（Absent / generic）:** 認知可能なポジションやクラフトがない。テンプレートと見分けがつかない。足かせとなるレベル。
- **2 — 平均未満（Below par）:** ある程度の意図は見られるが、一貫性がなく、模倣的で説得力に欠ける。他社と並べられた際に選ばれない。
- **3 — 有能 / 前提条件レベル（Competent / table-stakes）:** 堅実でプロフェッショナルだが平凡。期待値は満たすが、誰も独自のものとは見なさない。
- **4 — 強力 / 独自性あり（Strong / distinctive）:** 同業者よりも明らかに優位。発注者が気づき、選定理由として言及できる本物の強み。
- **5 — カテゴリー定義レベル（Category-defining）:** クラス最高峰で独自性があり、模倣が極めて困難。他社が追随・反応せざるを得ない基準を打ち立てている。

### 緊張関係の軸（次元9） — それぞれ1〜5点でスコアリング

ポジショニング要件から軸のラベルと1/3/5点の基準を読み取ります。例（記憶定着度 × 信頼性 の場合）:

- **記憶定着度（Memorability）** — 1: 即座に忘れられる · 3: 文脈の中では認識できる · 5: 忘れられず、話題に上り、独自に認知されている。
- **信頼性（Credibility）** — 1: リスキーまたは素人っぽく見える · 3: 安全で有能だが刺激はない · 5: 大手企業から信頼され、明白で安全な選択肢となっている。

競合を2×2の緊張関係マップにプロットします。ターゲット象限はポジショニング要件で指定されています。その象限に他に誰がいるかを突き止めることが、ベンチマーク分析の最も重要な成果です。

## データの収集方法

競合ごとに、以下の順序（コストの低いシグナルから順）で調査を進めます:

1. **競合自身のWebサイト** — ポジショニング、トーン、オファーのパッケージ化、価格姿勢、クライアント実績、マニフェスト/見解。トップページと代表的なケーススタディを記録。
2. **ケーススタディ / 実績** — エビデンスの深さ、定量化された成果、クライアント名。「主張しているだけ（asserted）」と「実証されている（proven: 数値、実名、検証可能）」を峻別。
3. **レビューディレクトリ（外部評価サイト）** — クライアント、プロジェクト規模、契約形態の裏付け → 信頼性とエンタープライズ適合性（例: Clutch.co や業界特化サイト）。
4. **LinkedIn** — チーム規模/体制、創業者のストーリー、投稿頻度 → ソートリーダーシップ、事業モデル。
5. **ポートフォリオ / クラフト系プラットフォーム** — クラフトの水準（デザイン掲示板、ショーリール、公開サンプルなど、業界固有のショーケース）。
6. **コンテンツ配信チャンネル** — ニュースレター/講演/執筆記事 → ソートリーダーシップの深さ。

**各次元で記録すべき内容:** スコア、1行の正当化理由、およびその根拠となったソースリンク/スクリーンショット。エビデンスのないスコアは無効です。

## バイアス管理（偏りの排除）

- **単一の総合スコアを作らないこと。** 各次元のスコアと緊張関係プロットは個別に報告します。加重平均は、戦略上極めて重要な「凹凸（非対称性）」を覆い隠してしまいます。
- **主張 vs 実証（Asserted vs Proven）。** 裏付けのない自己申告の主張については、信頼性/エビデンスのスコアを割り引きます。自社サイトのコピーはマーケティング宣伝であり、事実そのものではありません。
- **美的嗜好バイアス（Aesthetic affinity bias）。** レビュアーは自身の好みに合うスタジオを過大評価し、好みに合わない競合の商業的強みを過小評価しがちです。クラフトと信頼性は独立して評価してください。「地味で退屈」に見えるサイトが、実際にははるかに大きな大企業案件を獲得している場合があります。
- **新奇性 / 派手さバイアス。** 受賞歴のある派手な作品は目を引きますが、ビジネスとしての深みに欠けることがあります。信頼性を採点する前に外部ディレクトリや顧客実績で裏付けを取ってください。
- **生存者バイアス。** 目立ち、巧みに宣伝しているスタジオだけが市場のすべてではありません。レビューや業界ディレクトリで見つかる「地味だが強力な実力派」にも注目してください。
- **単独ではなくセット全体で較正（キャリブレーション）すること。** スコアを確定する前に、横並びで再確認します。ある競合の「4点」は、他の競合の「4点」と厳密に同じ水準を意味していなければなりません。外れ値は調整します。

## 競合プロファイルカード（出力フォーマット）

評価対象の競合ごとに1枚のカードを作成します — レポート作成の最小構成単位となります:

```
## <競合名>
- **プロファイル / ティア:** <ポジショニングの姿勢 · 専門領域 · 規模帯> / <Direct | Adjacent | Aspirational>
- **ワンライナー:** <彼ら自身の言葉による自己定義・ポジショニング>
- **モデル / 規模 / 地域:** <ソロ|マイクロ|ブティック> · <地域> · <価格/契約モデル>
- **注目すべきクライアント / エビデンス:** <実名実績、実証済み/自己主張のタグ付き>

### 評価次元スコア
| 評価次元 | スコア (1–5) | 正当化理由 (1行) | ソース |
|---|---|---|---|
| ポジショニングの明確性と独自性 | | | |
| ブランドボイス / 言語的独自性 | | | |
| ビジュアルアイデンティティとサイトのクラフト | | | |
| サービスオファーとパッケージ化 | | | |
| エビデンスと信頼性 | | | |
| エンタープライズ適合性 / 商業的成熟度 | | | |
| ソートリーダーシップ / 発信の存在感 | | | |
| 価格の透明性とエンゲージメントモデル | | | |

### 戦略的緊張関係プロット
- **[ポジショニング要件の軸1]:** <1–5> — <理由>
- **[ポジショニング要件の軸2]:** <1–5> — <理由>
- **象限:** <high/high | high-1/low-2 | low-1/high-2 | low/low>

### クライアントに対する示唆
- **学ぶべき強み:** <…>
- **突くべき弱み / 明らかになったホワイトスペース:** <…>
- **クライアントに対する脅威:** <…>
```

完成したプロファイルカードと緊張関係プロットを `competitive-report-structure` に引き渡します。

## アンチパターン

- **緊張関係の2軸を平均化すること。** クライアントの戦略的緊張関係の両極は、必ず個別にスコアリングおよび報告しなければなりません。平均化すると、両極間のギャップという重要な洞察が失われます。
- **エビデンスなしのスコアリング。** すべてのスコアには1行の理由とソースリンクが必要です。エビデンスのないスコアは単なる個人的感想に過ぎません。
- **単一の総合スコアを作成すること。** 各次元のスコアは個別に提示してください。加重平均はポジショニングに必要な非対称な強みを覆い隠してしまいます。
- **汎用的な記述子をそのまま機械的に適用すること。** 1〜5点の基準は、特定の次元や競合セットに合わせて適切に較正される必要があります。汎用記述子は出発点に過ぎません。
- **競合セットのスコープが絞られる前に実行すること。** まず `competitive-platform-analysis` を使用して、階層化され厳選されたセットを用意してください。無秩序なリストへのスコアリングは無関係な競合に対する労力の浪費となります。

## 関連スキル

- `competitive-platform-analysis` — 前提スキル。本スキルが評価対象とする階層化された競合セットを作成します。
- `competitive-report-structure` — 次のステップ。スコアリングされたプロファイルカードをクライアント向け納品レポートとして統合します。
