# Competitive Platform Analysis（競合プラットフォーム分析）

ベンチマーク評価を開始する前に、**「誰をベンチマーク対象とすべきか」**および**「どこで彼らを見つけるか」**を決定するためにこのスキルを使用します。競合分析の価値は、その前提となるフレームワークの質によって決まります。対象の選定を誤ると、クライアントが「無敵」に見えるか、あるいは「絶望的」に見えるかの極端な結果に陥ります。目指すべきは、網羅的な全数調査ではなく、意思決定に直結する論理的で確実な競合セットの構築です。

## 有効化のタイミング

- 競合ベンチマークプロジェクトを開始するにあたり、まず競合セットを定義する必要があるとき。
- どの企業が直接競合（Direct）/ 隣接競合（Adjacent）/ 目標・指標競合（Aspirational）の各ティアに属するか判断に迷うとき。
- 市場ランドスケープ（俯瞰図）レポートのために、論理的根拠があり厳選されたスコープが必要なとき。
- ポジショニング要件（ブリーフ）があり、そのポジションを争う相手を特定したいとき。
- `benchmark-methodology` を実行する前の初期ステップとして。

## クライアントのポジショニング要件（最初に確立すること）

セットのスコープを絞る前に、クライアントのポジショニング要件を確立します。まだ存在しない場合は、短い `brand-discovery` インタビューを行って引き出してください — **決して推測で捏造したり、盲目的に競合を選定したりしてはなりません**。要件には以下が含まれます:

- **アイデンティティ / 美的水準（レジスター）** — どのようなスタジオ/企業であり、自身をどのように見せているか。
- **提供価値（オファー）** — 提供しているサービスや製品。
- **ターゲット顧客** — 誰に対して販売しているか。
- **差別化要因** — クライアントが信じる参入障壁（堀）やポジショニングの論理。
- **スコープ決定への影響（Scoping consequence）** — 競合を重み付けする基準（例: サービス重複度や価格よりも、独自性の高さを優先するなど）。
- **戦略的緊張関係** — クライアントのホワイトスペースを定義する対となる2軸（例: 記憶定着度 × 発注しやすさ）。

**ポジショニング要件なしに進めてはなりません。** クライアントのレンズを通さずに作られた競合リストは、インテリジェンスではなく単なるノイズです。特に「スコープ決定への影響」は、どの競合が*真の強敵*（クライアントの参入障壁を脅かす存在）であり、どれが単にメニューが重複しているだけかを決定づけます。

## 選定基準

各候補について、以下の軸を把握します（選定とティア分けの両方を決定します）:

- **規模 / モデル** — ソロ、マイクロスタジオ（2〜8名）、ブティック（30名未満）、中堅代理店。クライアント自身の規模帯と一致させます（同規模帯のスタジオが現実の直接対決セットとなります）。
- **ニッチ / 専門性** — 候補の強みがクライアントのオファーとどれほど重複しているか。重複が密であるほど直接的になります。
- **地理 / 市場** — EU、米国、またはグローバルリモート。言語、対応タイムゾーン。クライアントと同じターゲット顧客を獲得しているかに留意します。
- **価格およびエンゲージメントモデル** — パッケージ化されたスプリント、リテイナー（顧問）、個別プロジェクト、日当制。明瞭か「要問い合わせ」か。ポジショニングの成熟度を示します。
- **ポートフォリオのスタイル** — 汎用的か、意見・主張が明確なエディトリアル調か、逆張り的（コントラリアン）か。クライアントの美的レジスターに近いほど、独自性を奪い合う相手となります。
- **技術の深さ / クラフトの成熟度** — クライアントの信頼性のストーリーに、プロセスの公開、オープンなツール開発、文書化されたシステムなどが含まれる場合に関連します。
- **ブランドの強さ** — そのスタジオ固有の言語的/視覚的アイデンティティがあるか、それとも他と代替可能か。クライアントのスコープ要件に基づいて重み付けします。

## プレイヤーの分類体系（マッピングすべき軸）

競合を業界特有の狭いカテゴリに分類するのではなく、全体像が特定の典型像に偏らないよう、いくつかの汎用的な軸に沿って分類します。これらの軸は、あらゆるクリエイティブ/プロフェッショナルサービス市場（デザイン、動画、コピーライティング、ブランディング等）に適用できます。まず各軸に沿って幅広く網羅し、その後最も示唆に富む候補に絞り込みます。

1. **ポジショニングの姿勢** — *ブランド主導 / エディトリアル型*（アイデンティティ、トーン、思想で勝負） vs *能力・機能主導型*（クラフト、納品スピード、実務成果で勝負）。両方の極をカバーします。
2. **専門性** — *専門特化*（1つの厳密な分野・領域） vs *総合型*（幅広いサービスメニュー）。
3. **規模 / モデル** — *ソロ / マイクロ* vs *ブティック* vs *中堅* vs *エンタープライズ規模*。同規模が直接競合、上位規模は目標・商業的成熟度の参照となります。
4. **契約フォーマット** — *プロダクト化*（名称付きスプリント、監査、定額パッケージ） vs *オーダーメイド*（個別プロジェクト / リテイナー）。
5. **独自性の姿勢** — *標準的 / 無難* vs *逆張り / マニフェスト主導*。
6. **エビデンス / 信頼モデル** — *成果主導*（数値指標、実名顧客、ケース深さ） vs *美的主導*（ポートフォリオ、受賞歴）。
7. **運営者のブランド力** — *代替可能* vs *熱狂的 / 固有の認知*（印象に残るソロブランドモデルを実証しているシニア独立系を含む）。
8. **市場 / リーチ** — *ローカル / 地域限定* vs *グローバルリモート*。

各候補を関連する軸にプロットします。ポジショニング、専門性、規模、市場のすべてにおいてクライアントの近傍に位置するものが**直接競合（Direct）**となります。

## 競合ティア（階層の決定）

最終的なセットを3つのティアにまとめます — この構造は最終レポートまで一貫して維持されます:

- **直接競合（Direct）** — 同規模、重複するオファー、同一のターゲット顧客。現実の直接対決の相手。
- **隣接競合（Adjacent）** — 部分的な重複（特定の能力のみ、または顧客規模が異なる）があり、境界線上で圧力をかけてくる存在。
- **目標・指標競合（Aspirational）** — 現在は直接競合していないが、そのブランド力や商業的成熟度が目指すべき基準となっているプレイヤー。
- *(代替手段の監視: ノーコード/AIツール、内製チーム、フリーランスなど — プロファイル対象ではなく脅威要因として注記)*

## 情報源（どこを調べるか）

必要な評価次元に応じて情報源を使い分けます:

- **ポートフォリオ / クラフト系プラットフォーム** — クラフトの品質、レンジ、美的水準（例: Dribbble, Behance, Vimeo 等）。
- **アワード / キュレーションされたショーケース** — クラフトの野心と業界評価。見栄えの良さに偏りがちなので商業的信頼性とクロスチェックする（例: Awwwards 等）。
- **競合自身のWebサイト** — ポジショニング、トーン、オファーのパッケージ化、価格姿勢、実名顧客、マニフェストに関する一次情報源。
- **LinkedIn** — チーム規模/体制、創業者のストーリー、投稿頻度、クライアントロゴ、所在地。
- **レビューディレクトリ** — レビュー、実名クライアント、案件規模、契約形態。商業的信頼性とエンタープライズ適合性の最も強力なシグナル（例: Clutch.co 等）。
- **オープン / 公開された成果物** — プロセスリポジトリ、公開サンプル、制作裏話: 深さとクラフトの透明性の証拠。
- **カンファレンス講演 / ポッドキャスト / ニュースレター** — ソートリーダーシップの深さと独自見解。

競合の属性を事実として扱う前に、**必ず少なくとも2つの情報源で裏付けを確認**してください（自社サイトの宣伝文句 ≠ 検証済みの成果）。

## スコアリングマトリクス・テンプレート（選定ステージ）

誰を本格的なベンチマーク評価に進めるかを決定するための軽量な事前フィルターです。1〜5点で採点し、独自性または信頼性の**いずれか**で高スコアを獲得した候補を残します（クライアントの戦略的緊張関係において、両極が示唆に富むためです）。

| 候補 | ポジショニングの姿勢 | 専門性 | 規模帯 | ティア | オファー重複度 (1–5) | 独自性 (1–5) | 商業的信頼性 (1–5) | クラフトの近さ (1–5) | 対象に含めるか？ |
|-----------|--------------------|----------------|-----------|------|---------------------|------------------------|------------------------------|------------------------|----------|

経験則（ポジショニング要件のスコープ指針に従って適用）:

- 高独自性 **かつ** 高信頼性 → 必須プロファイル対象（クライアントの目指す緊張関係が実現可能であることを証明している）。
- 高独自性、低信頼性 → 反面教師（印象には残るが発注しにくい — 学ぶべき潜在的失敗モード）。
- 高信頼性、低独自性 → クライアントが差別化の標的とすべき「有能だが忘れ去られる」ボリュームゾーン。
- 両方とも低い → 市場の幅広さを示すために必要な場合を除き除外。

## 本ステージの成果物

スコープが絞られ階層化された競合セット（通常は10〜18社の候補から8〜12社を選定）。それぞれに軸の位置、ティア、情報源リンクが付与され、`benchmark-methodology` に引き渡す準備が整った状態。

## アンチパターン

- **ポジショニング要件なしでスコープを定義すること。** クライアントのレンズを通さない競合リストはノイズです。
- **似ている企業をすべて列挙すること。** 目標は全数調査ではなく、論理的に防御可能な10〜18社の候補セットです。絞り込みのない網羅は後のベンチマークを破綻させます。
- **直接/隣接/目標のティアを曖昧にすること。** これらのティアは異なる戦略的目的を持ちます。混同すると意思決定に役立たないフラットなリストになります。
- **競合ごとに単一の情報源に頼ること。** 自社サイトのコピーはマーケティングであり事実ではありません。必ず2つ以上の情報源で検証してください。
- **いきなり本採点（スコアリング）に飛びつくこと。** 本スキルはセットのスコープ定義とティア分けを担当します。採点は `benchmark-methodology` が行います。

## 関連スキル

- `brand-discovery` — 競合セットのスコープを規定するポジショニング要件と戦略的緊張関係を確立するために最初に使用します。
- `benchmark-methodology` — 次のステップ。階層化されたセットを受け取り、9つの次元で各競合をスコアリングします。
