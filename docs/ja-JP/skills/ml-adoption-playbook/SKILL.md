# ML導入プレイブック (ML Adoption Playbook)

本スキルは、既存のソフトウェアエンジニアリングプロジェクトに機械学習（ML）モデルを導入するための適応的な方法論を提供します。MLの調査、疎結合化、学習、および統合のプロセスを構造化することで、従来のソフトウェア開発（SWE）とMLOpsの間のギャップを橋渡しします。

## 発動タイミング

- ユーザーが既存のコードベースに「MLを追加したい」「アルゴリズムを導入したい」と要求した場合。
- MLが使われていないアプリケーションへの新しいモデル（レコメンデーション、分類、予測など）の統合を計画する場合。
- エージェントが適応的にMLコンポーネントを構築、学習、デプロイするためのワークフローを組み立てる場合。

## フェーズ1: 課題の定式化と実現可能性の確認 (Problem Framing & Feasibility)

モデルのコードを書く前に、「なぜ」「どのように」を明確にします。
- **ヒューリスティックの確認:** 単純なルール（正規表現、ルールベースのソートなど）でより迅速に解決できないかを検討します。可能であればそこから着手します。
- **指標の定義:** MLモデルが改善を目指すビジネス指標（クリック率の向上、レイテンシの削減など）を定義します。
- **許容される予測ミスの予算 (Mistake Budget):** 「好ましくない予測」とは何か、またシステムがそれをどのように処理すべきかを定義します。

## フェーズ2: データの準備状況 (Data Readiness)

クリーンでアクセス可能なデータがなければMLは機能しません。
- **データソースの監査:** 学習データがどこに存在するか（本番DB、静的CSV、APIなど）を特定します。
- **データ契約 (Data Contract):** 入力データのスキーマを確立します。必要な特徴量は何か、欠損値がある場合にどう処理するかを定めます。
- **データ漏洩 (Data Leakage) の防止:** 提案されたデータ分割で、未来の情報が学習セットに混入しないよう徹底します（時系列データにおける時系列順分割など）。

## フェーズ3: アーキテクチャの統合と疎結合化 (Architectural Integration & Decoupling)

モデルの推論をコアのビジネスロジックと密結合させてはなりません。
- **API境界の設計:** モデルをAPIエンドポイントの背後（`fastapi-patterns` や `django-patterns` の活用）または専用のサービスクラス内に配置します。
- **フォールバック機構:** デフォルト状態を設計します。モデルの応答がタイムアウトしたりエラーをスローした場合、システムはハードコードされたルールへ安全にフォールバックする必要があります。
- **フィーチャーフラグ:** 新しいML推論呼び出しをフィーチャーフラグでラップし、安全にロールアウト（またはロールバック）できるようにします。

## フェーズ4: モデルの実装と学習 (Model Implementation & Training)

再現性と反復可能性を重視してコードを構造化します。
- **シンプルから始める:** まずはベースラインモデル（シンプルなscikit-learnのロジスティック回帰や、PyTorchの軽量線形層など）を構築します。
- **再現性の担保:** `pytorch-patterns` などのベストプラクティスを適用します。乱数シードの固定、デバイス非依存コードの記述、テンソルや配列の形状の明記を徹底します。
- **自動化されたエビデンス:** データ変換処理と推論スキーマに対するテストを必須とします。ベースラインと比較検証する評価スクリプトのないモデルを採用してはなりません。

## フェーズ5: MLOpsへの引き継ぎ (Handoff to MLOps)

ベースラインモデルが統合されたら、継続的な運用へと焦点を移します。
- **`mle-workflow` の参照:** 実験管理、モデルレジストリ、ドリフト検出のセットアップに向けてユーザーを誘導します。
- **CI/CD:** 既存のCIパイプラインにモデル評価ステップを追加し、将来のコミットによってモデルのパフォーマンスが劣化しないようにします。

## エージェントの反復ワークフロー

本プレイブックを通じてユーザーを支援する際、エージェントは以下を実行します：
1. アーキテクチャを提案する前に、**フェーズ1を完了するための質問**を行います。
2. フェーズ2で**データ契約のドラフトを作成**し、ユーザーの承認を得ます。
3. 学習ループを書く*前*に、フェーズ3で**疎結合インターフェース（API/Service）を実装**します。
4. フェーズ4でモデルを学習しアーティファクトを保存する**再現可能なスクリプトを提供**します。
